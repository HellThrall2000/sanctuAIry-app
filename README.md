# Sanctuary App

An elegant, privacy-first, on-device AI mental health & wellness companion built with Flutter and Google LiteRT / MediaPipe GenAI engine.

## Features
- **100% On-Device AI**: Powered by Google LiteRT / Gemma 2B local edge inference.
- **Complete Privacy**: Zero server calls, zero data logging. All conversations remain strictly local.
- **Biometric Lock**: Secure access via fingerprint or device passcode.
- **Mood Tracking & Journaling**: Local encrypted progress insights and daily wellness checks.

## Getting Started

1. **Install Flutter**: Ensure Flutter SDK 3.29+ and Android SDK 35/36 are installed.
2. **Fetch Dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run App**:
   ```bash
   flutter run
   ```
